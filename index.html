MOSAIC HELP

How to use Mosaic

Your editable architectural collage workflow.

1. Start — Upload Base, then upload or generate Master, or choose Continue with Base.

2. Groups — Select an area with Lasso, Rect, Oval or Wand. Use the + next to Groups to create one manually.

3. Options — Import an image and click Apply, or use AI Edit. Each option can be edited, renamed, deleted or regenerated.

4. Move / Skew — Drag an approved option or its four corner handles. Its mask follows the change.

5. Harmonize — Create a new full image from your approved collage and original Base.

6. Save / Open project — Save a .mosaic project file to continue editing later, including images, Groups, masks and Master history.

Shortcuts — Enter closes a lasso, Ctrl/Cmd+Z undoes, [ subtracts, ] adds, Esc clears a selection.
